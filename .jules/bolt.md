## 2025-02-13 - Optimize Canvas Redraws During Mouse Movement in React
**Learning:** During drawing interactions (e.g., pen, rectangle tool, etc.) via `mousemove` in React, calling a comprehensive `renderPipeline` that rebuilds the entire base stitched image from scratch on every single mouse event causes massive CPU overhead and jank. The heavy drawing operation (the base stitch and crops) is actually independent of the lightweight annotations being drawn.
**Action:** When composing complex canvases where a static, heavy background is overlaid with interactive user drawings, separate the background rendering into a memoized/cached stage. Check whether the background dependencies have actually changed before redrawing it. By only caching the base layer rendering and skipping the `ctx.drawImage` loop if inputs haven't changed, 60 FPS drawing responsiveness can be restored.
