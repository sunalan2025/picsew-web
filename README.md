# Picsew Web - 纯前端长截图拼接与编辑工具 ✂️

一个纯前端构建的长截图拼接与打码小工具（基于 React + TypeScript + Vite），支持智能重合度裁剪、添加手机壳边框、马赛克打码、PDF 导出与切片打包。无需安装任何环境，纯浏览器本地 Canvas 渲染，不上传服务器，保护隐私。

👉 **在线体验**: [https://sunalan2025.github.io/picsew-web/](https://sunalan2025.github.io/picsew-web/)

第一次使用可以先看 [三步上手说明](docs/QUICK_START.md)，或在应用首页点击「先用示例试试看」。

---

## 主要功能

1. **长图拼接与对齐**：批量导入多张截图，拖拽上下重合参考线调整每张图的接缝与遮挡，快速对齐。
2. **边缘裁切**：自由裁剪图片四周边缘，快速剔除聊天记录或网页里多余的状态栏与底部导航栏。
3. **手机套壳效果**：支持为长图一键套上主流手机外壳（带圆角、金属边框与刘海/灵动岛），并自动生成配套的时间电量状态栏，做演示分享时更美观。
4. **画笔与打码**：内置箭头、矩形框、画笔和马赛克模糊工具，方便在拼好的长图上标重点或快速遮盖敏感信息。
5. **多格式导出**：支持导出高清 PNG/JPEG、转换为分页/单页 PDF，或按指定高度分段切片打包成 ZIP 下载。
6. **操作回退**：支持撤销与重做（最多 50 步），手滑剪错可以随时退回。

---

## 移动端使用说明

- **iOS (iPhone) 添加为桌面 PWA**：用 Safari 打开在线链接，点击底部的「分享」→「添加到主屏幕」，即可像原生 App 一样全屏无边框打开。
- **Android APK**：基于 Capacitor 打包，拼好的长图可以直接保存进手机系统的下载目录/相册中。

## 本地运行

```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev

# 构建产物
npm run build
```

## 开发进展与验收

现已加入接缝放大精调、完整项目撤销、素材坐标标注、录屏区间选择、本地草稿恢复、离线应用与系统图片分享入口。导出使用独立的成品渲染器，避免工具辅助线或编辑状态影响结果。

完整实现范围、测试命令及大图/原生端限制见 [实现与验收状态](docs/IMPLEMENTATION_STATUS.md)。这些能力仍需真实 iOS/Android 设备和录屏素材验收，不代表与原版 Picsew 完全一致。

素材面板支持一键倒序并撤销。收到新版提示时，应用会先保存草稿再重新打开；更新后可恢复继续编辑。

开发检查：`npm run check` 会执行安全审计、lint、单元测试和构建；`npm run test:browser` 包含新手流程的桌面/手机浏览器测试，以及真实生产构建的离线更新和草稿保护测试。
