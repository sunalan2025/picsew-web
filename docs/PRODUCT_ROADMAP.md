# Picsew Web — 功能对齐与产品路线

## 产品目标
默认三步：导入截图 → 自动对齐并预览 → 保存/复制。高级工具通过悬浮面板按需启用，而不是固定占据桌面。

## 现有能力（已实现）
- 多图片纵向/横向拼接、重合度检测与手动微调
- 拖拽/文件选择导入、图片排序、逐边裁剪、分割、撤销/重做
- 画笔、箭头、矩形、文字、模糊和马赛克
- 设备套壳、状态栏、PNG/JPEG、PDF、分段 ZIP、复制图片
- 本地浏览器 Canvas 处理、不经云端上传

## 原版 Picsew 功能差距（官方文档 / App Store，2026-10-31 核对）
| 能力 | Web 当前状态 | 下一阶段建议 |
| --- | --- | --- |
| 多图无缝拼接 | 已有，继续加强自动识别可靠性 | 建立黄金截图样本测试及错缝预警 |

## 优先级
1. **P0**：安卓低版本保存兼容（#101）、纵横向拼接几何与测试（#102）、手机触控操作与大图稳定性。
2. **P1**：录屏导入转长图、网页扩展式整页截图、拖动缩略图排序、接缝置信度提示。
3. **P2**：水印体系、更多设备模板、HEIC/WEBP、OCR、自动化分享/URL Scheme。

## UX 验收
- 空白状态仅突出上传截图；上传完成自动进入画布。
- 大多数任务不需要打开侧栏，1 次导入 + 1 次导出。
- 所有现有高级选项通过五组工具访问，桌面和手机均为画布优先布局。
- 纵向和横向使用不同边缘匹配，切换方向不复用旧方向重合度。
