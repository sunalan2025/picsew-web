# 第一次使用 Picsew Web

不需要注册，也不用先调参数。可以先点首页的「先用示例试试看」，看看三张截图怎样变成一张长图。示例不会写入你的个人草稿；点「换成我的截图」即可开始。

## 1. 添加截图

- 在相册中按阅读顺序选择截图，也可以拖入图片或直接粘贴。
- 相邻截图留几行相同内容。例如，第二张也要截到第一张底部的一部分文字，系统才能找到连接位置。不要提前把这些重复内容裁掉。
- 推荐 PNG 或 JPEG 截图。若提示不支持 HEIC 等格式，请先在相册中另存为 JPEG 后添加。

## 2. 检查拼接

添加完成后会自动拼接，先看看长图里的文字有没有重复或缺失。

如果提示有连接需要检查，点「检查第一处」。看起来正常时点「这处看起来没问题」；有重影或错位时再用放大图和 +1 / −1 微调，不必一开始就理解像素参数。

多余边缘可以在「裁剪」中去掉；「标注与打码」也在裁剪面板中。改错了可以撤销。

## 3. 保存图片

直接点右上角「保存图片」，默认保存清晰的 PNG。

需要小一些的文件时，在第 3 步选择 JPEG。「更多保存选项」提供图片宽度、画质、PDF 和分段保存；普通长截图可以保持默认值。

手机上若相册里没有成品，请先到「文件 / 下载」或浏览器下载列表查找。是否能直接存入相册取决于系统；Android App 的保存窗口取消后会显示「已取消保存」。

## 遇到提示时怎么继续

| 提示 | 下一步 |
| --- | --- |
| 没有添加成功 / 格式不支持 | 从相册另存为 PNG 或 JPEG，重新选择原始截图 |
| 文件太大 / 尺寸过大 | 缩小截图，或分成几组拼接 |
| 有连接需要检查 | 先确认是否有重复或缺失文字；正常就确认，有错位再微调 |
| 保存失败 / 成品太大 | 点「减小尺寸再保存」，也可在更多选项中分段保存 |
| 有待导入的分享图片 | 先打开应用处理之前的分享，再分享下一组 |
| 草稿无法保存 | 先导出成品，并检查浏览器存储空间 |

图片和草稿保存在当前设备。草稿可能因清理浏览器数据而丢失，重要成品请及时保存。
