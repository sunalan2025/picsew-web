# 智能滚动拼接 2.0 — 算法和回归验证

## 已经完成
- **接缝搜索**：原来仅搜 600px；现在纵向和横向最多搜索 3600px，匹配前将边缘区域沿拼接轴缩小到最多 340px。返回原始图像像素单位。
- **鲁棒匹配**：比较多条中心像素列/行、跳过可能是固定状态栏的边界、对差异最大的部分采样做截尾平均。纹理不足和多个候选位置分数接近时返回“低置信度，不自动裁切”。
- **录屏动态选帧**：每秒约扫描四个候选时间点，不再平均保留帧；通过低分辨率内容位移估算，小滚动累计、静止帧跳过、倒退移动排除。快速跳跃尝试补抽中点（最多 48 次）。
- **用户操作**：低置信度接缝出现明显的复核入口，其他接缝无需手动操作；微调范围支持 >500px。
- **无云上传**：图片处理、录屏解析、导出仍在用户设备浏览器进行。

## 目前测试
单元/回归测试覆盖：纵向、横向、巨大重叠、固定顶部/底部栏、轻微 JPEG 类噪声、重复图案、空白、无关联图片、静止录屏、倒退滚动、滚动速度变化与抽帧边界。

CI 仅验证模拟像素输入、TypeScript 检查及 Vite 构建。**尚未在真实 iOS/Android 长录屏大样本上统计准确率，不应声称达到百分之百可靠，也没有测量整体识别准确率百分比。**

## 后续评测与改进
1. 采集经授权的 iOS/Android 真实视频片段，覆盖微信、浏览器、聊天记录、列表、图片流、固定导航栏、夜间模式、混合分辨率、屏幕录制不同帧率。
2. 按每段录屏记录人工标注的滚动偏移（px）；报告 MAE、接缝错位率、漏字/丢内容率、耗时、峰值内存，而非仅看主观截图。
3. 对固定导航栏/浮动组件考虑分离滚动内容区域及更精确的亚像素对齐；对动态视频和复杂转场支持手动标注起止时间。
4. 浏览器真实视频抽帧端到端测试、50 张上限压测、大型 Canvas 限额与分块导出。
